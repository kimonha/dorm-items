## 미검증 범위

- Docker Desktop이 실행되지 않아 실제 PostgreSQL 연결, 컨테이너 빌드 및 DB 컨테이너 재시작 데이터 보존은 미검증
- 외부 LLM 실제 성공 응답·실제 네트워크 시간 초과는 미검증 (실패 경로 및 집계는 검증)
- T16의 전체 서비스/DB 프로세스 재시작 시나리오는 미검증: PostgreSQL 테스트·Docker 재기동으로 추가 확인 필요
- 브라우저에서 실제 예약 시간이 도달한 뒤 사용·반납하는 전체 수동 흐름은 미검증: 자동 테스트의 주입 가능한 서버 시계로 검증

완료되지 않은 항목을 통과로 표시하지 않았습니다.
